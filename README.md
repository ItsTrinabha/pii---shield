# Cloak

Fail-closed PII gateway between business documents (PDF incl. scanned, PPTX, DOCX) and an LLM.

Start here: [docs/README.md](docs/README.md) (setup and usage). Results: [docs/RESULTS.md](docs/RESULTS.md).
Demo: `python -m pii_shield.app` (local web UI on http://127.0.0.1:8765; the older Streamlit demo is `streamlit run src/pii_shield/app/main.py`).
